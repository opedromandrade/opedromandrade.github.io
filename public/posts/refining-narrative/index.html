Refining the Narrative

Posted on Sep 25, 2026 DRAFT

I’ve been working and polishing my CV lately: tightening the content, reviewing every line. It’s a work in progress labor. It’s tricky task and when you’re my age you need to know what to cull and what to keep. What to rewrite and what to set in stone. There’s no exact formula for a CV that lands you a new or better job. 🤷

Since I’ve been a busy bee on GitHub anyway and writing everything in Markdown — even started using Obsidian — I thought: why not use Markdown to write and work on my CV? So I decided to rewrite the whole thing to Markdown.

When you start getting used to Markdown, you’ll get clarity. Everything looks more polished and intentional. No distracting factors and items. It becomes almost addictive to use it for everything you write. So once the content looks fine and all info reviewed, I noticed that the result at first lacks flavor and personality. So why not style it? A friend - and Lumo 💡- told me the best way is CSS for styling, and later Pandoc
for the full post-processing. It may look daunting, but it’s quite straightforward. ✨

Using Pandoc for the final compilation ensures consistency and a clean output across formats. I guess sometimes the best way to move forward is to revisit where you started. 🔄

🛠️ Markdown + CSS + Pandoc = a cleaner, sharper and more portable resume.
